# 项目代码跳转交付验收

本次交付覆盖 Java、Python、JS、JSX、TS、TSX 的本地项目定义跳转，Ctrl＋左右箭头位置历史，以及原有预览、编辑、保存和自动保存功能。操作与项目配置见 [code-navigation.md](code-navigation.md)，内网重建步骤见 [monaco-offline.md](monaco-offline.md)。

## 交付文件

产物放在仓库 `dist/` 下，生成文件不提交 Git。每个 zip/exe 旁均提供独立 `.sha256`，完整验收记录放在 `dist/navigation-validation/`。

| 文件 | 用途 |
| --- | --- |
| `electron/Sona-Code-2.3.1-Navigation-Test7.exe` | Windows x64 安装包，含独立审查修复，由干净源码在离线构建环境重建 |
| `Sona-Code-navigation-source.zip` | 已提交的源码归档，包含已构建的本地 Monaco 静态资源 |
| `Sona-Code-Windows-x64-offline-build.zip` | 锁定版本的完整内网构建依赖包 |
| `Sona-Code-navigation-third-party-sources.zip` | 同版第三方许可证和对应源码，安装包及内网包也包含这些内容 |

安装包约 749.5 MiB，内网构建依赖包约 1018.4 MiB，第三方源码包约 294.2 MiB。六语言服务及 JDK、Node、许可证和对应源码均随包交付；内网 npm 无需恰好保留相同版本。内网重新打包还需本机 Python 3.12 x64。

- Java 真实离线 Maven、Gradle 多模块导入通过；空 Maven 插件缓存保持离线，并显示导入失败。
- 浏览器实测 F12、候选选择、A→B→C 回退/前进、关闭目标后历史重开、跨项目定位、12 标签容量拒绝、设置页往返保留草稿和 Ctrl＋S 保存。实际 Ctrl＋点击另有浏览器验收记录。页面控制台错误和警告均为零。
- 组合输入与焦点边界、重载确认取消分支由状态测试验证；未将浏览器原生确认框或实际系统输入法的自动化失败记作实测通过。

- 完整性校验验证逐文件 SHA-256、转依赖运行时、原始许可证和对应源码；删除测试副本中的启动入口会正确拒绝打包。

## 实测边界

首次分析和内存数值来自小型验收项目，详见 JSON 报告。开发机单服务组约 8～11 秒，工作集约 Python 99 MiB、JS/TS 304～308 MiB、Java 802 MiB。最终 Test7 离线重建包首次分析约 7.7～11.2 秒，工作集约 Python 297 MiB、JS/TS 715～717 MiB、Java 1129 MiB；包内报告的进程树包含 sidecar 和双编辑器分析实例，不能视为单实例用量。大型业务项目及其缓存仍需内网实测。

干净重建目录较深，Python 测试环境曾触发 Windows 长路径限制。验收使用同一份资源复制到较短的普通目录，重新执行完整性校验后测试；建议源码解压和安装选择较短路径。

本次测试隔离配置、数据库、项目与端口，仅停止所属测试进程。用户正在运行的已安装版本和真实对话未改动。包内 sidecar、OpenCode 与 ConPTY 验收不等同于已安装桌面的退出、恢复和重启验收；后者仍需用户退出旧版后验证。

分支为 `feat/monaco-offline-editor`。GitHub 上传结果及最终文件 SHA-256 在交付消息和产物校验文件中记录，只有成功的推送才记为已上传。
