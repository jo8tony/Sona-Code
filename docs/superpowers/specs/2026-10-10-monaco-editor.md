# 本地代码预览、编辑和离线交付

用户已选择 Monaco，并授权开发、Windows 安装包验证、内网源码打包及推送 GitHub。

目录树单击文件进入文件树旁的固定代码面板，覆盖对话区，文件树保持可操作，关闭后返回对话。保留系统打开、定位、对话引用功能。Ctrl/Cmd+I 切换预览/编辑，Ctrl/Cmd+S 保存；按扩展名/文件名匹配语言，未知类型使用纯文本。多文件标签保留未保存内容。关闭文件或退出编辑面板需处理未保存修改；切换应用页面保留编辑状态。

按用户追加要求，支持独立、持久化的默认编辑/自动保存开关。首次预览、手动保存；启用后可直接编辑，停止输入 1 秒自动保存。任何保存失败暂停该文件自动重试，保留草稿和错误提示，手动保存成功或重新加载后恢复。保存期间的新修改继续保留并随后保存。

读写仅限已登记项目内的现有普通文件，拒绝路径穿越、符号链接、Windows reparse point、设备路径和 ADS。支持不超过 2 MiB 的 UTF-8 文本（含 BOM）；保存保留 BOM、LF/CRLF/CR 和文件权限。混合换行和过长行只读，二进制与其他编码提示系统打开。内容 SHA-256 为 revision，保存检测外部变化，409 时保留本地修改并允许重新加载；不提供强制覆盖。

Monaco 0.57.0、语言模块、五个 Worker、CSS、字体和许可证全部位于本地静态目录。延迟加载编辑器，不使用 CDN；JSON schema 外部请求关闭。网页、Python wheel、PyInstaller sidecar 和桌面安装包包含相同资源，并校验完整性。

交付包含 Windows Electron 验证安装包，以及同平台内网源码打包用依赖包和操作说明。构建严格离线模式缺少资源时立即失败，不回退外网。完整应用的模型服务地址由用户配置；代码编辑器本身不依赖模型或 OpenCode 服务。

边界：不执行代码，不把 HTML 当网页渲染，不建立 LSP 服务；Python/Go/Java 等提供语法高亮，JSON/JS/TS/CSS/HTML 使用 Monaco 内置语言能力。
