## 安装包

- Windows x64：NSIS `.exe`，内置固定版本 OpenCode CLI（1.18.32）。
- macOS Apple Silicon / Intel：对应架构 `.dmg`，OpenCode 从 PATH 或自定义路径加载。

Windows 原生终端需要 Windows 10 1809 或更新系统；AI shell 命令建议安装 Git for Windows。macOS 安装包采用 ad-hoc 签名，未经过 Apple notarization。
