## Windows 桌面与兼容性改进

- 关闭窗口（包括 Alt+F4）默认隐藏到系统托盘，代理、工作区任务和终端继续运行。
- 点击托盘图标或右键选择「打开 Sona Code」恢复窗口；完全退出请在托盘右键菜单选择「退出」。
- 再次启动应用恢复已有窗口，避免重复后端抢占端口。
- 桌面后端使用 UTF-8 输出，改善 Windows 中文日志。
- Windows 工作区进程清理增加超时与失败兜底，安装包测试清理完整 sidecar 进程树。
- 实际安装包冒烟测试覆盖窗口关闭/重新打开、中文及空格项目路径、随包 OpenCode V1 会话和 ConPTY 命令执行。

## 安装包

- Windows x64：NSIS `.exe`，内置固定版本 OpenCode CLI（1.18.32）。
- macOS Apple Silicon / Intel：对应架构 `.dmg`，OpenCode 从 PATH 或自定义路径加载。

Windows 原生终端需要 Windows 10 1809 或更新系统；AI shell 命令建议安装 Git for Windows。macOS 安装包采用 ad-hoc 签名，未经过 Apple notarization。
