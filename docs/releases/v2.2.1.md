## 工具状态与会话体验

- 写入文件、查询网络等工具处于等待或运行状态时，图标显示呼吸效果；完成或失败后停止动画。遵循系统减少动态效果设置。
- 修复侧栏运行中会话的 loading 图标不旋转的问题。
- 修复多次编辑同一文件时增删行数缺失的问题；原生差异数据缺失的覆盖写入显示实际写入行数。
- 加快会话切换：取消旧请求，复用最近六个会话的画面和滚动位置，同项目切换不再重复加载模型与技能配置。
- 消息返回后立即显示，避免被较慢的差异或队列接口阻塞；减少其他会话事件和未变化数据触发的重复刷新。
- 修复流式消息元数据更新时丢弃已拉取消息内容的问题，并补充刷新隔离、缓存和统计回归覆盖。

## 安装包

- Windows x64：NSIS `.exe`，内置固定版本 OpenCode CLI（1.18.32）。
- macOS Apple Silicon / Intel：对应架构 `.dmg`，OpenCode 从 PATH 或自定义路径加载。

Windows 原生终端需要 Windows 10 1809 或更新系统；AI shell 命令建议安装 Git for Windows。macOS 安装包采用 ad-hoc 签名，未经过 Apple notarization。
